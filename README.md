# Proyecto Base de Datos I

> Proyecto académico de diseño e implementación de una base de datos desde cero, siguiendo el proceso de requisitos a Diagrama Entidad-Relación (DER).

## 📋 Estructura del Proyecto

Este repositorio documenta el proceso completo de diseño de una base de datos:

1. **Entrevista y captura de requisitos** — Recopilación de necesidades del cliente
2. **Análisis y especificación** — Identificación de entidades, atributos y restricciones
3. **Diseño conceptual (DER)** — Diagrama Entidad-Relación con Draw.io
4. **Mapeo relacional** — Conversión a tablas SQL
5. **Implementación** — Scripts de creación e inserción de datos
